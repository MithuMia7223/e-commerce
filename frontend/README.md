# E-Commerce Frontend

Tkinter-based frontend for the e-commerce application using ttkbootstrap.

## Features
- User authentication (login/signup)
- Product catalog browsing
- Shopping cart management
- Checkout process
- User profile
- Like and comment on products

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Make sure the backend is running on `http://localhost:8002`

3. Run the frontend:
```bash
python main.py
```

## Requirements
- Python 3.7+
- ttkbootstrap
- requests
